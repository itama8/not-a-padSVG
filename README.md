# not-padgtp

A supercharged notepad: plain text, a tiny UI, and an x-ray you hold to see.

The website lives in [`site/`](site/). It's one self-contained HTML file with no build step.
Every push to `main` that touches `site/` deploys it to GitHub Pages.

- Hold anywhere to peek at the x-ray, tap to keep it on.
- `site/reference/` holds the original reveal prototype.
